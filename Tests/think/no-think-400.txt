  --- Write a Python function that reverses a string.
  [models\glm47flash-v3\model.tootega] Here is a simple and efficient Python function to reverse a string.

In Python, strings are **immutable**, meaning you cannot change them in place. The most "Pythonic" way to do this is using slicing.

```python
def reverse_string(text):
    """
    Reverses the input string.
    
    Args:
        text (str): The string to be reversed.
        
    Returns:
        str: The reversed string.
    """
    return text[::-1]

# Example usage:
original = "Hello, World!"
reversed_text = reverse_string(original)

print(f"Original: {original}")
print(f"Reversed: {reversed_text}")
```

### How it works:
The syntax `text[::-1]` is a slice notation.
*   The first colon (`:`) tells Python to take the whole string.
*   The second colon (`:`) indicates a step.
*   `-1` tells Python to step backwards through the string, effectively reversing it.

### Alternative (Using a Loop)
If you are doing this for a homework assignment that requires you to understand the logic behind the scenes, here is how you would do it using a `for` loop:

```python
def reverse_string_loop(text):
    reversed_text = ""
    for char in text:
        reversed_text = char + reversed_text
    return reversed_text
```
